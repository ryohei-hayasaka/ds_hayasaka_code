# GraphMaker

TGA、DSC、IR、UV-Vis、GPC、粒度分布、温度ロガー、SSカーブ、粘着力のデータを比較・解析し、
Excelで直接編集できるグラフへ出力するWindowsデスクトップアプリです。
ローカルPCまたは社内共有フォルダ内で完結し、外部通信は行いません。

科学計算・解析ロジックは前版から**そのまま移植**しています（20モジュール、変更なし）。
作り直したのはUI層だけです。

## 画面構成

**単一ウィンドウ・3ペイン構成**です。前版のようにメイン画面とグラフ画面を行き来する必要はありません。

```
┌───────────────────────────────────────────────────────────────────────┐
│  GraphMaker   [TGA ▾]   📁 …\demo_data\TGA\raw_data     [Excelへ出力]  │ アプリバー
├────────────┬────────────────────────────────────────┬─────────────────┤
│ データ  ⟨  │ X 25 – 800  Y 0 – 105 [自動範囲] 読取X  │ 系列（常時表示）  │
│            │ ┌────────────────────────────────────┐ ├─────────────────┤
│ 検索│ツリー │ │                                    │ │  処理│解析│結果  │
│            │ │        グラフ（常時表示）            │ │                 │
│            │ │                                    │ │  インスペクタ    │
│ CSV一覧     │ └────────────────────────────────────┘ │                 │
│[グラフへ追加]│                                        │                 │
├────────────┴────────────────────────────────────────┴─────────────────┤
│ ● 8件を追加しました                                                     │ ステータスバー
└───────────────────────────────────────────────────────────────────────┘
```

- **グラフはどの操作中も隠れません。** DSCの4点選択もIRの規格化位置指定も、この1画面で完結します。
- 左レール（データ）と右インスペクタは、`⟨` / `⟩` ボタンで**折りたたみ**できます。折りたたむとグラフが全幅になります。
- **軸範囲と読取Xはグラフ直上のツールバー1箇所だけ**にあります。
- **系列テーブルはインスペクタの上段に常時表示**（縦分割の固定パネル、タブではありません）です。
  解析・結果タブへ切り替えても系列選択が隠れないため、系列を選び直すためだけにタブを往復する必要がありません。
  色スウォッチのクリックで色変更、凡例名のダブルクリックでインライン編集、`表示`列のクリックで一時的な非表示ができます。
  非表示は削除ではなく、Excel出力には従来どおり全系列が含まれます。
- 系列テーブル下段のタブは **処理 / 解析 / 結果** です。
  - `結果` タブは**9モードすべてで**そのモードの結果を表示します。UV-VisとGPCは解析を持たないため、
    表示中データの点数とX/Y範囲の要約を表示します。
  - 解析を持たないモード（TGA以外の一部）や処理を持たないモードでは、該当タブ自体を表示しません。

### 通知

モーダルダイアログは**破壊的操作の確認**（系列削除、プロファイル削除）と
**OSレベルの失敗**（ファイル書き込み不可等）にのみ使用します。
それ以外は次の2層で伝えます。

1. **インライン検証** — 入力欄の近くに赤字で理由を表示
2. **ステータスバー** — 成功・進捗・情報。数秒で自然に薄くなる

条件を満たしていないボタンは押せる状態にせず、**disabledにして理由をツールチップで表示**します。

### 配色とタイポグラフィ

グラフの系列色は **Okabe–Ito 系パレット**（色覚多様性に配慮、白背景・モノクロ印刷でも識別可能）です。
UIの色・フォント・余白は `src/graphmaker/theme.py` に一元化しており、
**他のモジュールに16進カラーリテラルは存在しません**（`tests/test_ui_contracts.py` で検証）。

フォントは `Yu Gothic UI` →`Meiryo UI` → `Segoe UI` の順にフォールバックし、
解析結果の数値は等幅の `Consolas` で桁を揃えます。
起動時に高DPI対応（`SetProcessDpiAwareness`）を行い、グラフ描画もスケール係数を掛けます。

## 起動

会社での利用は、内容を確認しやすいソース版ランチャーを標準とします。配布フォルダ内の
`GraphMaker.pyw` をダブルクリックしてください。コンソールを表示してエラーを確認する場合は
`GraphMaker.bat` を使用します。`src`、ランチャー、`requirements.txt` は同じ配置のまま使用してください。

利用PCにはPython 3.9以降と `openpyxl==3.1.5` が必要です。TkinterとCSV解析はPython標準機能を使います。
この版はソース版ランチャー専用です。PyInstaller版EXEは作成・収録していません。

## 共通操作

1. アプリバーの「測定モード」で `TGA`、`DSC`、`IR`、`UV-Vis`、`GPC`、`粒度分布`、`温度ロガー`、`SSカーブ`、`粘着力` のいずれかを選択します。
2. 「フォルダ…」で測定データのあるフォルダまたは共有フォルダを選びます。
3. フォルダツリーを選択すると、直下のCSVファイル名だけを取得します。この時点ではCSV本文を読みません。
4. ファイルを複数選択して「グラフへ追加」を押すと、保存済み読込プロファイルをバックグラウンドで判定し、初めて本文を読みます。
5. グラフはその場で更新されます。`系列`タブで凡例名・色・表示/非表示・再読込・削除を行います。
6. 「Excelへ出力」で、グラフと全点データを同じ `Data` シートへ保存します。

左パネルは「フォルダ検索」と「フォルダ」の2タブで、どちらも同じCSV一覧へつながります。
「フォルダ検索」は選択したルートフォルダの配下を再帰的に検索して、フォルダ名に検索ワードを含む
フォルダを一覧します（大文字小文字は区別しません、カンマ・スペース区切りで複数ワードのOR検索も
可能です）。検索ワードは測定モードごとに記憶され（既定値はモード名自体）、一覧に出た結果は
さらに下の絞り込みボックスでテキスト検索できます。「フォルダ」タブは従来どおりフォルダツリーを
手動で辿る操作です。

CSVを1つ選択して「読込設定」を押すと、先頭最大300行のプレビューと装置別の読込設定を確認できます。
ヘッダー自動検索、行番号、キーワード相対位置、列名／列番号、文字コード、区切り文字、単位、6種類の終了条件に対応します。
「この設定でテスト」は表示中の曲線や解析結果を変更せず、実際の開始・終了行、点数、X/Y値、列、単位、メタデータ、警告を確認します。
設定は今回だけ適用するか、JSONプロファイルとして保存できます。

組み込みプロファイルは `profiles` フォルダ、ユーザープロファイルは
`%LOCALAPPDATA%\GraphMaker_Python39\profiles` に保存されます。組み込み設定は上書き・削除できないため、変更するときは複製してください。
破損したユーザーJSONはそのファイルだけを無効化し、ほかのプロファイルとアプリの起動は継続します。

9つの測定モードは、読み込み済み曲線・表示順・色・凡例名・軸範囲・選択状態を別々に保持します。
DSC/IRのブランク、IRの0点・規格化、粒度分布の指定粒径規格化、新規モードの試料情報と解析結果は
アプリ終了まで保持し、`settings.json`には保存しません。ルートフォルダとフォルダ検索の検索ワードは
測定モードごとに`%LOCALAPPDATA%\GraphMaker_Python39`の`settings.json`へ保存します。

### 読取X

全9モード共通です。グラフ直上の「読取X」に数値を入れるか、通常時にグラフをクリックすると、
表示中の処理済み系列を補間して `系列`タブの `Y値` 列に表示します。
IRなどの降順Xに対応し、粒度分布だけは表示軸と同じlog10(X)座標で補間します。

## 対応CSVと読込プロファイル

以下の従来形式は組み込みプロファイルとして自動認識します。実機CSVは、固定形式へ書き換えなくても「読込設定」で
前置き情報、列順、開始・終了位置、区切り文字、単位を明示できます。未知の列や単位を値の大きさから推測することはありません。

### TGA

```text
Record_ID,Time_min,Temperature_C,Mass_mg
```

先頭の有効な `Mass_mg` を100%として重量%を計算します。先頭重量は0より大きい必要があります。
`解析`タブに全系列のTd5、Td50、Td95を表示し、任意の残存率から最初の下向き交差を線形補間してTdxも算出できます。
元CSVやMass_mgは変更せず、到達しない残存率は理由とともに「算出不可」と表示します。

### DSC初版

最低限 `Temperature_C` と、次のいずれか1つの熱流列が必要です。

```text
Temperature_C,HeatFlow_mW
Temperature_C,HeatFlow_W_g
Temperature_C,HeatFlow_mW_mg
```

現在のデモ形式は次の4列です。

```text
Record_ID,Time_min,Temperature_C,HeatFlow_mW
```

組み込み形式では列名から単位を決定します。読込プロファイルでは熱流単位、試料重量列、昇温速度列を明示できます。
熱流単位が不明な場合も温度・熱流曲線は読み込めますが、融解エンタルピーは算出不可になります。各形式ともUTF-8（BOMあり／なし）とCP932に対応します。

### IR初版

吸光度データの固定3列形式です。不明な列名や透過率・反射率は推測して読みません。

```text
Record_ID,Wavenumber_cm-1,Absorbance
```

横軸は高波数を左、低波数を右に表示します。DSCとIRではモード共通ブランクに加え、系列ごとに「共通を使用・補正なし・個別指定」を選べます。
IRでは0点波数と規格化波数を数値またはグラフクリックで指定できます。処理は必ず原データ→ブランク補正→0点合わせ→規格化の順です。
0点波数と規格化波数が同じ場合など、処理できないときは設定値を保持して具体的な警告を表示し、既存曲線を消しません。

### UV-Vis

```text
Record_ID,Wavelength_nm,Absorbance
```

軸タイトルは `Wavelength (nm)` / `Absorbance` です。IRと同様に**ブランク補正**（モード共通ブランクに加え、系列ごとに「共通を使用・補正なし・個別指定」を選択）と
**規格化**（共通規格化波長または系列別、数値入力またはグラフクリックで指定）に対応します。処理順序は原データ→ブランク補正→規格化です。
0点合わせ、λmax、ピーク面積などの解析はまだ行いません。

### GPC

```text
Record_ID,RetentionTime_min,RI_mV
```

軸タイトルは `Retention time (min)` / `RI response (mV)` です。IRと同様に**規格化**（共通規格化保持時間または系列別）と
**0点合わせ**（系列ごとに保持時間を指定、グラフクリックにも対応）に対応します。処理順序は原データ→0点合わせ→規格化です。
ブランク補正、ベースライン補正、ピーク解析、分子量校正、Mn/Mw/Mzなどの算出はまだ行いません。

UV-VisとGPCもUTF-8 BOM、UTF-8、CP932に対応します。必須列名は固定で、不明な列を推測して読み替えません。追加列は無視します。

### 粒度分布初版

次の2種類の固定列名だけを受け付けます。粒径はµm、体積頻度は%として保持し、読込時の再規格化や並べ替えは行いません。

```text
Record_ID,ParticleDiameter_um,VolumeFrequency_percent
Record_ID,ParticleSize_um,Volume_percent
```

横軸は `Particle diameter (µm)` の底10対数軸、縦軸は未規格化時 `Volume (%)`、規格化時 `Normalized volume` です。
共通粒径、規格化なし、系列別粒径を選択でき、系列別粒径は数値入力またはグラフクリックで指定できます。
指定位置に測定点がなければ元の粒径に対して線形補間し、その位置の体積頻度を1として規格化します。
基準値が1×10⁻⁶以下、範囲外、0以下などの場合は元データへフォールバックして理由を表示します。

### 温度ロガー

`Time_min / Temperature_C` を標準形式とし、読込プロファイルでは秒・時間をmin、Kを℃へ変換できます。
グラフ上の4点で前基線、ピーク探索、後基線を指定し、前後範囲の全点から1本のベースラインを回帰します。
上向きピークの開始、ピークトップ、終了、正のピーク面積（℃・min）を算出します。
ファイル読込時に**変化点自動候補**（傾き閾値法）が自動実行され、平滑化・傾き算出・端部ノイズ推定から
4点を推定して即座に解析します（候補が見つからない場合はその旨を通知）。「解析」タブの「自動候補」ボタンで
選択系列に対して再実行することもできます。ピーク面積はDSCの融解解析と同様に、区間内の実測点で
グラフ上に塗りつぶし表示されます。

### SSカーブ

`Extension_mm / Force_N` を読み込みます。系列ごとの幅（mm）、厚み（µm）、L0（mm）と、
補正なし・先頭点・選択点・数値入力の0点設定からStrain（%）とStress（MPa）を計算します。
厚みは計算時にµmからmmへ変換します。**幅・厚み・L0が未入力の間はグラフに何も表示されません**
（グラフ上にその旨を表示します）。最大応力候補は測定後半の最大値ですが、降伏点は自動検出せず、
ユーザーが選択した2点範囲内の最大応力点として算出します。手動点修正と手動範囲によるヤング率回帰にも対応します。

### 粘着力

`Distance_mm / Force_N` を読み込み、系列ごとの試料幅（新規系列は25 mm）から `F × 25 / W` でN/25 mmへ換算します。
選択した距離範囲を台形積分し、距離で除した距離加重平均を算出します。
SSと粘着力の試料情報ダイアログでは、選択セルの値を全系列へ代表値として適用できます。
ダイアログはExcel風に操作できます。セルをクリックして選択し、印字可能文字を直接入力すればダブルクリック
無しで編集を開始でき、`Enter`で下のセルへ、`Tab`で右のセルへ移動しながら連続入力できます。矢印キーでも
セル間を移動できます。編集中の`Enter`はセルの確定・移動にのみ使われ、ダイアログの「適用」ボタンが
誤って押されることはありません。

## DSC解析

DSC曲線を追加すると、Tg範囲と融解範囲の自動候補をバックグラウンドで計算します。結果は候補として表示され、
ユーザーが「採用」または「除外」を選択します。元CSVは変更しません。

### 入力条件

- 熱流単位：`mW`、`W/g`、`mW/mg`、不明
- 昇温速度：`Time_min` がある場合は温度差から自動推定。画面で変更可能
- 試料重量：総熱流 `mW` のエンタルピー計算時にmgで入力。SS/粘着力と同じ「試料情報入力」ダイアログから設定します
  （値を変更しても自動再解析はされず、「自動候補」または「算出」を押した時点の値が使われます）
- 吸熱方向：上向き／下向き
- 平滑化：奇数点の移動平均。Tg変曲点検出だけに使用し、元データとは別表示

### Tg解析・融解解析

- 前後ベースラインを個別に最小二乗直線で計算
- 変曲点近傍の接線と前ベースラインの交点をTgオンセット、段差の半分をTg中点、平滑化曲線の変化率からTg変曲点を計算
- 融解は前後ベースライン間を主探索範囲として、吸熱方向を補正したオンセット、ピーク、終了温度を計算
- `W/g` と `mW/mg` は比熱流として処理。総熱流 `mW` は試料重量mgで割って比熱流へ変換
- `ΔH = ∫q(T)dT × 60 / β` でJ/gへ換算。表示値は正値、内部結果には元符号を保持

単位、昇温速度、総熱流に対する試料重量が不足している場合、温度結果は表示しますが、融解エンタルピーは「算出不可」と表示します。

### グラフ上の4点選択

`解析`タブの「Tg 4点選択」「融解 4点選択」を押すと、**同じ画面のグラフ**をクリックして
前基線開始・前基線終了・後基線開始・後基線終了の4点を温度の低い順に選べます。

- クリック位置のX座標を温度として使用し、プロット領域外のクリックは無視します
- 選択中は4本の縦破線、番号、前後ベースライン範囲を仮表示します
- 「1点戻す」、右クリック、Escキー、「選択解除」で修正またはキャンセルできます。キャンセルしても既存結果と採用状態は変わりません
- 4点選択後も数値欄で微調整できます。解析開始と前基線開始、解析終了と後基線終了は連動します
- 複数曲線を表示している場合は、`系列`タブで解析対象を1系列だけ選択してから開始します

### 解析結果と注釈

`結果`タブにファイル名、昇温／冷却区分、Tg 3値、融解3温度、融解エンタルピー、解析状態、警告を
小数点以下2桁で表示します。行を選ぶと解析対象の系列が切り替わります。

グラフでは、Tg・融解範囲、平滑化曲線、各ベースライン、Tg解析点、融解解析点、積分面積を
`解析`タブのチェックボックスで個別に表示／非表示にできます。解析点の数値補正にも対応します。

## Excel出力

- `Data` シートのA1から全点データを配置し、`D5`付近にExcelネイティブの編集可能な散布図を重ねます。`Chart`シートは作成しません。
- データのヘッダーは無装飾、列幅は約7です。
- グラフタイトルは表示せず、グラフエリアとプロットエリアは白、プロット枠・X軸線・Y軸線は黒1.5 pt、補助線なし、内向き目盛という論文向けの書式です。
- タイトル削除後の余白を詰め、軸タイトル・目盛・凡例が収まる範囲でプロット領域を広げています。
- グラフの大きさは約18×12 cm、軸タイトルはArial 14 pt太字、目盛ラベルと凡例はArial 12 pt標準です。
- 系列名、色、表示順、熱流単位、軸範囲をアプリから引き継ぎます。
- DSC/IRは画面に実際に表示している処理済みデータを出力し、ヘッダーへブランク名、規格化波数、処理状態、失敗理由を記録します。IRのExcel横軸も高波数から低波数です。
- UV-Visは系列ごとに `Wavelength_nm / Absorbance`、GPCは `RetentionTime_min / RI_mV` の2列を全点出力します。
- 粒度分布は画面に表示中の `ParticleDiameter_um / VolumeFrequency_percent` または `ParticleDiameter_um / NormalizedVolume` を全点出力し、指定粒径と失敗理由をヘッダーへ記録します。ExcelのX軸も底10対数軸です。
- TGA、DSC、温度ロガー、SSカーブ、粘着力では、データ列から2列以上空けて同じ`Data`シートへ解析結果表も無装飾で出力します。
- Excel上で系列、色、軸、タイトル、位置、サイズを編集できます。


`plot_view.py` の入力は必ず `DisplaySeries` です。モード固有の意味付けは `panels.py` が
`PlotOverlay`（帯・面・曲線・直線・マーカー）として渡すため、描画側にモード分岐はありません。

`processing.py` / `display_series.py` / `new_mode_analysis.py` は移植後、UV-Vis・GPC対応や
温度ロガーの変化点自動候補のためにモード非依存な形へ拡張しています（`BLANK_CAPABLE_MODES` /
`ZERO_CAPABLE_MODES` / `NORMALIZATION_CAPABLE_MODES` によるモード判定、`suggest_temperature_change_points`
など）。既存モード（IR/DSC）の計算結果自体は変更していません。`panels.py` には共有ロジックを
まとめた `NormalizationPanelMixin`（`BlankPanelMixin` と組み合わせて `IrPanel`/`UvVisPanel`/`GpcPanel`
が利用）を追加しています。

### デモデータ

- TGA：`demo_data/TGA/raw_data`
- DSC：`demo_data/DSC/raw_data`
- IR：`demo_data/IR/raw_data`
- UV-vis吸光度：`demo_data/UV-Vis/raw_data`、`Record_ID / Wavelength_nm / Absorbance`、200～800 nmを1 nm間隔
- GPC-RI：`demo_data/GPC/raw_data`、`Record_ID / RetentionTime_min / RI_mV`、0～30 minを0.02 min間隔
- 粒度分布：`demo_data/ParticleSize/raw_data`、`Record_ID / ParticleDiameter_um / VolumeFrequency_percent`、0.1～1000 µmを対数間隔
- 温度ロガー：`demo_data/TemperatureLogger/raw_data`、`Time_min / Temperature_C`、0～40 minを0.1 min間隔、上向き温度ピーク10系列
- SSカーブ：`demo_data/SSCurve/raw_data`、`Extension_mm / Force_N`、0～20 mmを0.1 mm間隔、降伏・ひずみ硬化・破断を含む10系列
- 粘着力：`demo_data/Adhesion/raw_data`、`Distance_mm / Force_N`、0～100 mmを0.5 mm間隔、定常剥離区間を含む10系列

いずれもアプリ開発・表示確認用の合成データです。実物質の同定、定量、分子量校正には使用できません。

### 設計上のルール（テストで検証）

`tests/test_ui_contracts.py` が次を機械的に検証します。

- `theme.py` 以外に16進カラーリテラルが存在しない
- `messagebox` の使用は `confirm_destructive` と `report_os_error` の2関数だけ
- 旧UIモジュール（`gui.py` / `graph_window.py` ほか）が復活していない
- `Toplevel` はダイアログ以外に存在しない（グラフが別ウィンドウへ戻らない）
- `LabelFrame` の入れ子を作らない
- numpy / pandas / matplotlib を導入していない

`tests/test_python39_compatibility.py` が PEP 604 union、`match` 文、`zip(strict=)`、
`slots=True` の不在と、全モジュールのimportを検証します。
