# GraphMaker

TGAモードのメイン画面では、選択した1系列の正規化重量％からTd5、Td50、
Td95を自動算出します。任意の残存率を入力すると、最初の下向き交差を
線形補間してTd10やTd12.5などのTdxも算出できます。元CSVやMass_mgは
変更せず、到達しない残存率は理由とともに「算出不可」と表示します。

グラフウィンドウの系列表では、「色」セルのダブルクリックで色を変更し、
「凡例名」セルのダブルクリックで凡例名をその場で編集できます。凡例名は
Enterで確定、Escで取り消します。「凡例名を編集」ボタンによる複数系列の
一括編集も引き続き利用できます。

GraphMakerは、TGAの重量曲線比較、DSCのTg・融解解析、吸光度IR曲線のブランク補正・規格化に加え、UV-Vis吸光度、GPC-RI信号、粒度分布を比較表示し、Excelで直接編集できるグラフへ出力するWindowsデスクトップアプリです。ローカルPCまたは社内共有フォルダ内で完結し、外部通信は行いません。

## 起動

会社での利用は、内容を確認しやすいソース版ランチャーを標準とします。配布フォルダ内の
`GraphMaker.pyw` をダブルクリックしてください。コンソールを表示してエラーを確認する場合は
`GraphMaker.bat` を使用します。`src`、ランチャー、`requirements.txt` は同じ配置のまま使用してください。

利用PCにはPython 3.12以降と `openpyxl==3.1.5` が必要です。TkinterとCSV解析はPython標準機能を使います。
PyInstaller onedir版も互換確認用に維持していますが、通常の社内配布ではソース版ランチャーを使用します。

## 共通操作

1. 左上の「測定モード」で `TGA`、`DSC`、`IR`、`UV-Vis`、`GPC`、`粒度分布` のいずれかを選択します。
2. 「ルートフォルダを選択」で測定データのあるフォルダまたは共有フォルダを選びます。
3. フォルダツリーを選択すると、直下のCSVファイル名だけを取得します。この時点ではCSV本文を読みません。
4. ファイルを複数選択して「グラフへ追加」を押すと、保存済み読込プロファイルをバックグラウンドで判定し、初めて本文を読みます。
5. 「グラフウィンドウを開く」で、比較グラフを別ウィンドウに表示します。同じボタンをもう一度押した場合は新しい画面を増やさず、開いているグラフを前面へ出します。
6. グラフウィンドウで曲線の凡例名・色変更、再読込、削除、軸範囲の手動指定・自動設定を行えます。色セルのダブルクリックで個別色を変更でき、「色を変更」では複数系列へ同じ色を一括適用できます。「凡例名を編集」では全系列を表形式で連続編集できます。
7. 「Excelへ出力」で、グラフと全点データを同じ `Data` シートへ保存します。

CSVを1つ選択して「読込設定」を押すと、先頭最大300行のプレビューと装置別の読込設定を確認できます。
ヘッダー自動検索、行番号、キーワード相対位置、列名／列番号、文字コード、区切り文字、単位、6種類の終了条件に対応します。
「この設定でテスト」は表示中の曲線や解析結果を変更せず、実際の開始・終了行、点数、X/Y値、列、単位、メタデータ、警告を確認します。
設定は今回だけ適用するか、JSONプロファイルとして保存できます。

組み込みプロファイルは `profiles` フォルダ、ユーザープロファイルは
`%LOCALAPPDATA%\GraphMaker\profiles` に保存されます。組み込み設定は上書き・削除できないため、変更するときは複製してください。
破損したユーザーJSONはそのファイルだけを無効化し、ほかのプロファイルとアプリの起動は継続します。

6つの測定モードは、読み込み済み曲線・表示順・色・凡例名・軸範囲・選択状態を別々に保持します。DSC/IRのブランク、IR規格化、粒度分布の指定粒径規格化はアプリ終了まで保持し、`settings.json`には保存しません。UV-VisとGPCでは解析パネルを表示せず、生データの比較表示とExcel出力のみを行います。

系列一覧は、DSCでは各系列の補正に実際に使ったブランクデータ名を表示し、IRではそれに加えて規格化ピーク波数（cm⁻¹）を表示します。補正・規格化を行っていない系列は「なし」と表示します。削除済みのブランクも指定名を保持し、既知の規格化波数を適用できなかった場合は「未適用」と表示します。

メイン画面はデータ選択、DSC解析条件、解析結果、採用・除外の管理に使用します。大きなグラフ、系列操作、表示範囲、解析注釈、4点選択、Excel出力はサイズ変更可能なグラフウィンドウにまとめています。グラフウィンドウを閉じて開き直しても、読み込み済み曲線、凡例名、色、順序、軸範囲、DSC解析条件・結果・採用状態・注釈の表示設定は保持されます。

## 対応CSVと読込プロファイル

以下の従来形式は組み込みプロファイルとして自動認識します。実機CSVは、固定形式へ書き換えなくても「読込設定」で
前置き情報、列順、開始・終了位置、区切り文字、単位を明示できます。未知の列や単位を値の大きさから推測することはありません。

### TGA

```text
Record_ID,Time_min,Temperature_C,Mass_mg
```

先頭の有効な `Mass_mg` を100%として重量%を計算します。先頭重量は0より大きい必要があります。

### DSC初版

最低限 `Temperature_C` と、次のいずれか1つの熱流列が必要です。

```text
Temperature_C,HeatFlow_mW
Temperature_C,HeatFlow_W_g
Temperature_C,HeatFlow_mW_mg
```

現在のデモ形式は次の4列です。

```text
Record_ID,Time_min,Temperature_C,HeatFlow_mW
```

組み込み形式では列名から単位を決定します。読込プロファイルでは熱流単位、試料重量列、昇温速度列を明示できます。
熱流単位が不明な場合も温度・熱流曲線は読み込めますが、融解エンタルピーは算出不可になります。各形式ともUTF-8（BOMあり／なし）とCP932に対応します。

### IR初版

吸光度データの固定3列形式です。不明な列名や透過率・反射率は推測して読みません。

```text
Record_ID,Wavenumber_cm-1,Absorbance
```

横軸は高波数を左、低波数を右に表示します。DSCとIRではモード共通ブランクに加え、系列ごとに「共通を使用・補正なし・個別指定」を選べます。IR規格化も共通波数、規格化なし、個別波数を選択でき、個別波数は数値入力またはグラフクリックで指定できます。グラフで選んだ波数はその系列へ直ちに適用され、メイン画面とグラフウィンドウの一覧へ反映されます。処理は必ず原データ→ブランク補正→IR規格化の順です。失敗した系列は警告付きで、ブランク失敗なら原データ、規格化失敗なら未規格化データを表示します。

### UV-Vis初版

吸光度データの固定3列形式です。生データの値と並び順をそのまま保持し、横軸は通常方向で表示します。

```text
Record_ID,Wavelength_nm,Absorbance
```

軸タイトルは `Wavelength (nm)` / `Absorbance` です。初版ではブランク補正、規格化、λmax、ピーク面積などの解析は行いません。

### GPC初版

RI検出器データの固定3列形式です。生データの値と並び順をそのまま保持し、ピークを加工せず通常方向で表示します。

```text
Record_ID,RetentionTime_min,RI_mV
```

軸タイトルは `Retention time (min)` / `RI response (mV)` です。初版ではブランク補正、ベースライン補正、ピーク解析、分子量校正、Mn/Mw/Mzなどの算出は行いません。

UV-VisとGPCもUTF-8 BOM、UTF-8、CP932に対応します。必須列名は固定で、不明な列を推測して読み替えません。追加列は無視します。

### 粒度分布初版

次の2種類の固定列名だけを受け付けます。粒径はµm、体積頻度は%として保持し、読込時の再規格化や並べ替えは行いません。

```text
Record_ID,ParticleDiameter_um,VolumeFrequency_percent
Record_ID,ParticleSize_um,Volume_percent
```

横軸は `Particle diameter (µm)` の底10対数軸、縦軸は未規格化時 `Volume (%)`、規格化時 `Normalized volume` です。共通粒径、規格化なし、系列別粒径を選択でき、系列別粒径は数値入力またはグラフクリックで指定できます。指定位置に測定点がなければ元の粒径に対して線形補間し、その位置の体積頻度を1として規格化します。基準値が1×10⁻⁶以下、範囲外、0以下などの場合は元データへフォールバックして理由を表示します。

## DSC解析

DSC曲線を追加すると、Tg範囲と融解範囲の自動候補をバックグラウンドで計算します。結果は候補として表示され、ユーザーが「採用」または「除外」を選択します。元CSVは変更しません。

### 入力条件

- 熱流単位：`mW`、`W/g`、`mW/mg`、不明
- 昇温速度：`Time_min` がある場合は温度差から自動推定。画面で変更可能
- 試料重量：総熱流 `mW` のエンタルピー計算時にmgで入力
- 吸熱方向：上向き／下向き
- 平滑化：奇数点の移動平均。Tg変曲点検出だけに使用し、元データとは別表示

### Tg解析

- 前後ベースラインを個別に最小二乗直線で計算
- 変曲点近傍の接線と前ベースラインの交点をTgオンセットとして計算
- 前後ベースライン間の段差の半分をTg中点として計算
- 平滑化曲線の変化率からTg変曲点を計算
- 「Tg解析」を押した後、グラフ上で前基線開始・前基線終了・後基線開始・後基線終了の4点を温度の低い順に選択
- 4点選択後に「算出」を押して再計算。解析範囲、前基線、後基線の数値欄と双方向に同期

### 融解解析

- 前後のデータから融解ベースラインを計算
- 前後ベースライン間を主探索範囲として、吸熱方向を補正したオンセット、ピーク、終了温度を計算
- 指定した融解解析範囲を積分範囲として使用
- 「融解解析」を押した後、グラフ上で前基線開始・前基線終了・後基線開始・後基線終了の4点を選択し、「算出」で再計算
- `W/g` と `mW/mg` は比熱流として処理
- 総熱流 `mW` は試料重量mgで割って比熱流へ変換
- `ΔH = ∫q(T)dT × 60 / β` でJ/gへ換算
- 表示値は正値、内部結果には元符号を保持

単位、昇温速度、総熱流に対する試料重量が不足している場合、温度結果は表示しますが、融解エンタルピーは「算出不可」と表示します。

### グラフ上の4点選択

- クリック位置のX座標を温度として使用し、軸ラベル・凡例・グラフ余白のクリックは無視します。
- 選択中は4本の縦破線、番号、前後ベースライン範囲、Tg変化部分または融解ピーク部分を仮表示します。
- 「1点戻す」、右クリック、Escキー、「選択解除」で修正またはキャンセルできます。キャンセルしても既存結果と採用状態は変わりません。
- 4点選択後も数値欄で微調整できます。解析開始と前基線開始、解析終了と後基線終了は連動します。
- 複数曲線を表示している場合は、解析対象を「グラフ上の曲線」で1系列だけ選択してから開始します。試料重量、昇温速度、解析範囲、結果は系列ごとに保持します。

### 解析結果と注釈

結果表にはファイル名、昇温／冷却区分、Tg 3値、融解3温度、融解エンタルピー、解析状態、警告を小数点以下2桁で表示します。

グラフでは、Tg・融解範囲、平滑化曲線、各ベースライン、Tg解析点、融解解析点、積分面積を個別に表示／非表示にできます。範囲変更後はTg解析・融解解析を別々に再実行できます。解析点の数値補正にも対応します。

## Excel出力

- `Data` シートのA1から全点データを配置し、`D5`付近にExcelネイティブの編集可能な散布図を重ねます。`Chart`シートは作成しません。
- データのヘッダーは無装飾、列幅は約7です。
- グラフタイトルは表示せず、グラフエリアとプロットエリアは白、プロット枠・X軸線・Y軸線は黒1.5 pt、補助線なし、内向き目盛という論文向けの書式です。
- タイトル削除後の余白を詰め、軸タイトル・目盛・凡例が収まる範囲でプロット領域を広げています。
- グラフの大きさは約18×12 cm、軸タイトルはArial 14 pt太字、目盛ラベルと凡例はArial 12 pt標準です。
- 系列名、色、表示順、熱流単位、軸範囲をアプリから引き継ぎます。
- DSC/IRは画面に実際に表示している処理済みデータを出力し、ヘッダーへブランク名、規格化波数、処理状態、失敗理由を記録します。IRのExcel横軸も高波数から低波数です。
- UV-Visは系列ごとに `Wavelength_nm / Absorbance`、GPCは `RetentionTime_min / RI_mV` の2列を全点出力します。編集後の凡例名と色をExcelネイティブグラフへ引き継ぎます。
- 粒度分布は画面に表示中の `ParticleDiameter_um / VolumeFrequency_percent` または `ParticleDiameter_um / NormalizedVolume` を全点出力し、指定粒径と失敗理由をヘッダーへ記録します。ExcelのX軸も底10対数軸です。
- Excel上で系列、色、軸、タイトル、位置、サイズを編集できます。

## 開発・テスト

### UV-Vis / GPC / 粒度分布デモデータ

- UV-vis吸光度：`demo_data/UV-Vis/raw_data`、列は`Record_ID / Wavelength_nm / Absorbance`、200～800 nmを1 nm間隔
- GPC-RI：`demo_data/GPC/raw_data`、列は`Record_ID / RetentionTime_min / RI_mV`、0～30 minを0.02 min間隔
- 粒度分布：`demo_data/ParticleSize/raw_data`、列は`Record_ID / ParticleDiameter_um / VolumeFrequency_percent`、0.1～1000 µmを対数間隔

いずれもアプリ開発・表示確認用の合成データです。実物質の同定、定量、分子量校正には使用できません。

Python 3.12以降を使用します。解析機能はPython標準ライブラリだけで実装しています。

```powershell
python -m pip install -r requirements.txt -r requirements-build.txt
$env:PYTHONPATH=(Resolve-Path 'src').Path
python -m unittest discover -s tests -v
python -m tga_analyzer
```

ポータブル版の作成:

```powershell
.\build_portable.ps1 -PythonExe python
```

出力先は `dist\GraphMaker\GraphMaker.exe` です。通常の社内利用ではEXEではなく、上記のソース版ランチャーを使用してください。
